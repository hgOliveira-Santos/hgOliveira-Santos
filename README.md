## Projetos em Destaque

### Modelo Previsor do Risco de Empréstimos

Aplicação fullstack para a classificação do risco de crédito usando Machine Learning. Construído com Go (REST API), Python (Modelo de Machine Learning) e React. Arquitetura de
microsserviços com comunicação HTTP entre serviços e containerização com Docker.
[🔗 Repositório Completo](https://github.com/hgOliveira-Santos/credit-risk-model)

### Classificador de Qualidade de Diamantes com KNN

Aplicação do algoritmo K-Nearest Neighbors para prever a categoria de corte dos diamantes, com pipeline completo de pré-processamento, validação e análise de desempenho.  
**Resultado:** 72,27% de acurácia no conjunto de teste.  
[🔗 Repositório Completo](https://github.com/hgOliveira-Santos/knn-diamonds-classifier)

---

### Previsão de Salário com Regressão Linear

Modelo de regressão linear para prever o salário anual com base nos anos de experiência, incluindo EDA, treinamento e avaliação com métricas de erro (MAE, MSE, RMSE).  
**Resultado:** Erro médio absoluto de ~6.286 dólares.  
[🔗 Repositório Completo](https://github.com/hgOliveira-Santos/linear-regression-salary)

---

### Análise de Dados de Matérias-Primas Agrícolas

Exploração detalhada de dados históricos de preços de commodities agrícolas, com limpeza, tratamento e visualizações para identificar tendências e correlações.  
[🔗 Explore o Repositório](https://github.com/hgOliveira-Santos/Analise-Materiais_Agricultura)
